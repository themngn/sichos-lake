                          # started directly in autostart.lua since PAM alone isn't
                          # reliable in this setup (see the xdg-portal/polkit note above).

## Dark-mode plumbing note
# This session's systemd --user graphical-session.target never activates, so
# xdg-desktop-portal doesn't come up via systemd on its own — without it, GTK4/
# libadwaita apps (Nautilus) never receive the dark-mode signal at all. Fix (already
# in autostart.lua): the three portal daemons above are launched directly as plain
# processes, bypassing systemd, followed by:
#   gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
#   gsettings set org.gnome.desktop.interface gtk-theme 'adw-gtk3-dark'
# Verified working: Nautilus renders dark.
